从名单到人工复核

  1. 建立名单

    导入 X 数据档案里的 data/following.js，或直接粘贴用户名。也可打开自己的「正在关注」页面，点击扩展、确认列表属于自己，再点「开始自动收集」。工具会滚动并保存关注名单，自然到底结束后自动清理本轮未出现且符合条件的旧本地记录；手动读取一次的方式仍可使用，但不会触发清理。

  2. 补充公开发帖记录

    点击「自动检查发帖时间」，选择范围和数量，点击「开始检查」并按浏览器提示授予可选的 X 网站访问权限。工具会在另一个 X 标签页中逐个检查名单；请保留控制页，可随时停止。也可继续手动打开「帖子」页、回到顶部后通过扩展读取保存，或录入已核实的日期。读取到的都只是页面样本。

  3. 筛选和复核

    设置天数阈值后，逐个复核候选。点击账户行的「取消关注」，按提示允许读取 X 页面，等待检测就绪后在新窗口使用 X 原生按钮自行取关。确认完成后请保留窗口，等待本地记录移除。若之前已经取关但记录仍在，可重新打开该账户；核实当前未关注且记录属于当前登录账户后，会自动同步本地记录，无需重新关注或扫描名单。取消操作、状态不明确或同步前关闭窗口时会保留记录。「撤销本地移除」只恢复本地记录，不会重新关注。名单自动清理及撤销仍在「同步记录」中查看。

数据与使用范围

此版本免费，不读取 Cookie，也不会代你点击 X 的关注或取关按钮。关注名单收集和发帖时间检查是分别启动的两步。发帖检查须由你点击开始并授予可选的 x.com 网站访问权限；默认最多检查 5,000 个账户，账户之间间隔 1 秒，另需页面加载与观察时间。检查失败、受保护或无法确定日期的账户仍需核实，不会因为没有读到帖子就被判为不活跃。名单收集的进度可在 X 页内查看，其标签页隐藏时会暂停；发帖检查的进度请在控制页查看。名单收集可在弹窗或页内面板停止；发帖检查可在控制页或弹窗停止，关闭或刷新控制页也会停止。清空本地名单会停止运行中的任务。X 限制非 API 自动化，自动滚动及页面分析不等于获得平台许可，也不能保证账号不受限制。

收集名单时，每次滚动后等待约 2.5 秒；到底部且约 20 秒没有新账户时停止，一轮最多 20 分钟、500 次滚动或 10,000 个账户，不保证覆盖完整名单。名单没有发帖记录时仍为「待补充数据」。数据只保存在当前浏览器。独立网页与扩展有不同的存储空间，可用 JSON 备份迁移。请勿导入完整账户 ZIP，以免包含无关隐私数据。
